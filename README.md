# arthurs-arena

Arthur's stickman fighting game, built in Scratch, with an Android tablet in mind.

The playable boss arena is `projects/arthurs-arena-bosses.sb3`. Open it in the [Scratch editor](https://scratch.mit.edu/projects/editor/) with **File → Load from your computer**, then click the green flag. `BOSSES.md` explains the three bosses and how to remix them. `projects/BLOCK_LISTING.md` lists every block.

The original template is [Stickman Battle](https://scratch.mit.edu/projects/732904827) by onigirikun_2009. `STARTER_GUIDE.md` is the longer plan. `CODEX_REVIEW.md` records the review notes from 2026-11-03.
