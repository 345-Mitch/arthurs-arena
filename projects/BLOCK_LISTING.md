# Block listing for Arthur's Arena bosses

Generated by `tools/build_bosses_sb3.py` from the same blocks that are inside
`projects/arthurs-arena-bosses.sb3`. If this file and the project ever disagree,
run the script again. Do not edit this file by hand.

Each heading is a sprite. Each stack is the blocks in order, the way they look
in Scratch. Square brackets are words typed into a block. Parentheses are numbers
or menu choices.

Which Fight is 1 Rival, 2 Brute, 3 Ivy, 4 Quake.
Health: Arthur 100, Rival 10, Brute 24, Ivy 24, Quake 30.
Arthur's hits: punch 5, kick 8.
Their hits: Rival 6, Brute 10, Ivy 8, Quake 12.

## Arthur Bar

Color bar. Green above 60 percent, yellow above 30, then red.

Costumes: green, yellow, red, track

```

    show
    go to x: [-220] y: [110]

      set [Arthur Max Health] to [1]
    end
    set [Bar Percent] to (((Arthur Health) / (Arthur Max Health)) * [100])
    if <(Bar Percent) > [100]> then
      set [Bar Percent] to [100]
    end
    if <(Bar Percent) < [0]> then
      set [Bar Percent] to [0]
    end
    if <(Bar Percent) > [60]> then
      switch costume to (green)
    else
      if <(Bar Percent) > [30]> then
        switch costume to (yellow)
      else
        switch costume to (red)
      end
    end
    set size to ((Bar Percent) * [0.7]) %
  else
    hide
  end
end
```
